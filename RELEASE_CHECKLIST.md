# Public-release checklist

- [ ] Confirm the final repository title and paper title.
- [ ] Add every author and affiliation to `CITATION.cff`.
- [ ] Select and approve a software license; replace `LICENSE_PENDING.md`.
- [ ] Audit upstream benchmark and reconstructed-baseline license notices.
- [ ] Deposit the frozen artifact bundle in a durable archive (for example,
      Zenodo or an institutional repository), add its DOI/URL, and verify all
      hashes in `artifacts/manifest.json`.
- [ ] Test the documented workflow on a fresh Linux environment.
- [ ] Confirm that no dataset records, model weights, credentials, absolute
      machine paths, or private patient information are present.
- [ ] Replace provisional citation text after the paper receives an identifier.
- [ ] Tag the exact paper release and archive the corresponding Git commit.
