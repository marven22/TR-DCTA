# AgentDojo TR-DCTA all-97 protocol v1

Frozen before execution. This descriptive full-dataset analysis includes every
official AgentDojo v1.2.2 user task: 78 multi-call tasks form three-stage
archives and 19 single-call tasks form two-stage archives. All 949 within-suite
user/injection pairs are screened. Exactly three executable injection origins
are deterministically selected per user task; the user task, not a correlated
cross-product pair, is the statistical unit.

All three origins rotate as truth. Complete provenance is evaluated once and
33%/67% missing provenance under five distinct masks. For two-stage archives,
the numbers of compatible lineage completions are 1/2/4; for three-stage they
are 1/2/8. Quarantine capacity equals archive depth, so every terminal slot
matters. Budgets are 2, 4, and 8; a budget larger than the candidate set audits
the full candidate set.

All frozen methods and 50 paired random repetitions are evaluated. The pooled
all-97 result is reported with two-stage, three-stage, and suite breakdowns.
Ten thousand paired task-bootstrap draws give descriptive 95% intervals. The
original balanced 32-task study remains the confirmatory analysis; this later
all-dataset run cannot retroactively replace its held-out status.
