# External artifact bundle

The repository intentionally excludes large generated ledgers and raw outputs.
`manifest.json` records the exact relative path, byte count, and SHA-256 digest
of every external input needed by the final evaluation runners.

Before public release, upload these artifacts to a durable archive and replace
the manifest's `archive_url` and `archive_doi` null values. A GitHub release is
possible, but a DOI-bearing research archive is preferable for a paper artifact.

After downloading/extracting the bundle at the repository root, run:

```bash
python scripts/check_artifacts.py --manifest artifacts/manifest.json
```

Raw outputs generated by a reproduction remain ignored by Git.
